📖 Descripción del proyecto
Espacio Sariri es un espacio interdisciplinario dedicado a la evaluación y tratamiento de personas de todas las edades con necesidades de desarrollo, comunicación y bienestar emocional.

Este sitio web está construido con HTML, CSS y JavaScript puro, sin frameworks pesados, priorizando la velocidad, accesibilidad y experiencia de usuario. Está optimizado para SEO, redes sociales y dispositivos móviles.

✨ Características principales
✅ Diseño 100% Responsive — Se ve perfecto en móviles, tablets y desktop.
✅ Formulario de contacto con Formspree.
✅ Integración con WhatsApp — Botones para contacto directo con mensajes predefinidos.
✅ Pestañas interactivas — Para describir tratamientos (Psicopedagogía, Psicología, etc.) sin recargar la página.
✅ Modal de Obras Sociales — Lista desplegable de coberturas.
✅ Animaciones sutiles y efectos de vidrio (glassmorphism) — Diseño moderno y atractivo.
✅ Optimizado para SEO y redes sociales — Metadatos Open Graph y Twitter Card listos.
✅ Envío de CV por mailto — Para reclutamiento de profesionales.

🛠️ Tecnologías utilizadas
HTML5 — Estructura semántica.
CSS3 — Diseño responsivo y animaciones.
JavaScript (Vanilla) — Interactividad sin frameworks.
Bootstrap 5.3 — Grid system y componentes (navbar, modales, tabs).
Font Awesome 6.5 — Íconos vectoriales.
Google Fonts (Montserrat) — Tipografía moderna y legible.
Formspree.io — Backend para formularios sin servidor.
WebP — Imágenes optimizadas para carga rápida.
